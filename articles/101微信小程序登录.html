            # 微信小程序登录流程

            # 1 整体时序图

            sequenceDiagram
    participant 用户
    participant 小程序
    participant 开发者服务器
    participant 微信服务器

    用户->>小程序: 点击登录
    小程序->>微信服务器: wx.login() 获取临时 code（5 min）
    微信服务器-->>小程序: code
    小程序->>开发者服务器: HTTPS 发送 {code}
    开发者服务器->>微信服务器: jscode2session(appid, secret, code)
    微信服务器-->>开发者服务器: openid + session_key (+ unionid)
    开发者服务器->>开发者服务器: 查库/生成业务 token（JWT/SessionId）
    开发者服务器-->>小程序: 返回业务 token
    小程序->>小程序: wx.setStorageSync('token', token)

            # 2 六步拆解（逐行背诵）

            步骤 关键代码 必须记住的参数/返回值 面试追问点
            1 触发 无 bindtap="login" 为什么放 onLaunch 而不是 onShow
            2 取 code wx.login() 返回 code 长度 32，有效期 5 min code 只能用一次，二次调 40163
            3 发 code wx.request({url: '/api/login', data:{code}}) 域名需配置到小程序后台「request 合法域名」 必须是 HTTPS+备案域名
            4 换票据 GET https://api.weixin.qq.com/sns/jscode2session 必填：appid、secret、js_code、grant_type 成功返回 JSON：
            {openid, session_key, unionid, errcode}
            5 建会话 后端逻辑 把 openid 作为主键，生成 JWT 或 3rd-session session_key 永不返回给小程序
            6 本地存 wx.setStorageSync('token', token) 后续 wx.request header 带 Authorization: Bearer <token> 退出小程序 token 仍然存在

            # 3 安全落地清单（逐条可落地）

            风险点 防御措施 检查方式
            中间人窃听 全链路 HTTPS + TLS1.2+ 抓包应无法看到明文 code/token
            AppSecret 泄露 只保存在服务器环境变量 代码仓库搜索不到 secret
            token 重放 设置过期时间（如 7 天）+ Redis 续签 token 解码查看 exp 字段
            业务域名伪造 小程序后台 → 开发 → 开发设置 → 服务器域名 request 域名必须在此列表
            session_key 泄露 绝不返回给前端，只用于解密 查看接口返回体是否包含 session_key

            # 4 高频追问与一句话答案

            Q1: token 过期用户正在操作怎么办？
            A: 在 wx.request 拦截器里捕获 401，自动 wx.login 续签，用户无感。

            Q2: 同一个微信用户换手机登录，openid 会变吗？
            A: 不会；openid 与 appid 绑定，同一小程序内终身唯一。

            Q3: 如何同时拿到手机号？
            A: 先完成上面 6 步拿到 session_key，再用 <button open-type="getPhoneNumber"> 拿到 encryptedData，后端用 session_key 解密即可。

            # 5 速记口令

            登录六步曲：
            触发 → 取码 → 送码 → 换票 → 建会话 → 本地存
            安全四件事：
            HTTPS 全链路，AppSecret 服务器藏，token 有寿命，域名白名单。
