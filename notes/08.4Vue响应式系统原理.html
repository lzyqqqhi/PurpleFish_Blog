# Vue响应式系统原理

  • 要点

    • 通过 Proxy 对数据读取/设置进行拦截，并在 effect 执行时自动收集依赖
    • 支持多层嵌套对象、数组等复杂结构的响应式
    • 提供 shallowReadonly/readonly 等多种保护策略

  • Proxy：Vue 3 采用 Proxy 来实现响应式，提供更高效的性能和更强的灵活性。

  • Object.defineProperty：Vue 2 使用的方式，功能相对有限，无法直接监听数组和对象的新增属性。

# Object.defineProperty（Vue 2）

  1. 初始化流程

    walk(obj) {
  Object.keys(obj).forEach(key => defineReactive(obj, key))
}
defineReactive(obj, key, val) {
  const dep = new Dep()
  Object.defineProperty(obj, key, {
    get() {
      Dep.target && dep.addDep(Dep.target)   // 收集 watcher
      return val
    },
    set(newVal) {
      val = newVal
      dep.notify()                           // 通知所有 watcher
    }
  })
  if (isObject(val)) walk(val)               // 递归
}

  2. 限制 · 只能劫持已经存在的 key；后续新增 key 需要 Vue.set。 · 数组索引、length 无法拦截。 · 无法监听 Map/Set。 · 深层对象一次性递归，大表/树形数据初始化慢。

# Proxy（Vue 3）细节

  1. 基本思路

    const proxy = new Proxy(target, {
  get(target, key, receiver) {
    track(target, key)              // 依赖收集
    const res = Reflect.get(target, key, receiver)
    return isObject(res) ? reactive(res) : res   // 懒递归
  },
  set(target, key, value, receiver) {
    const hadKey = hasOwn(target, key)
    const oldVal = target[key]
    const result = Reflect.set(target, key, value, receiver)
    if (!hadKey) trigger(target, key, 'add')
    else if (value !== oldVal) trigger(target, key, 'set')
    return result
  },
  deleteProperty(target, key) {
    const hadKey = hasOwn(target, key)
    const result = Reflect.deleteProperty(target, key)
    hadKey && trigger(target, key, 'delete')
    return result
  }
})

  2. 优点 · 对象级别拦截，新增/删除 key 无额外 API。 · 原生支持数组索引、length、Map/Set/WeakMap。 · 懒代理：深层属性只有被访问时才会递归，启动更快。 · 内存占用更低：WeakMap 缓存避免重复代理；SSR 可直接跳过 Proxy。

功能 Vue 2 Vue 3
添加根级响应式属性 Vue.set(obj, key, val) obj[key] = val
删除根级响应式属性 Vue.delete(obj, key) delete obj[key]
通过索引替换数组项 Vue.set(arr, idx, val) arr[idx] = val
