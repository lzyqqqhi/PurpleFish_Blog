# Vue生命周期

  • Vue2生命周期与钩子一览
钩子 能否访问 data 能否访问 DOM 典型用途
beforeCreate ❌ ❌ 很少用；可加非响应式全局属性
created ✅ ❌ 发 ajax、事件总线 $on、初始化非响应式数据
beforeMount ✅ ❌ 服务端渲染相关，SSR 期间可在此钩子注入全局数据
mounted ✅ ✅ 操作 DOM、第三方库初始化（echarts、swiper）
beforeUpdate ✅ ✅ 手动移除监听、保存滚动位置
updated ✅ ✅ 依赖 DOM 更新后的操作（nextTick 内）
beforeDestroy ✅ ✅ 解绑全局事件、定时器、websocket
destroyed ✅ ✅ 打日志、埋点
  • keepAlive钩子
    • activated：组件从缓存切回前台触发，替代 mounted 做耗时操作。
    • deactivated：组件被缓存时触发，替代 beforeDestroy 做清理。

# Vue3生命周期变化

  • 选项式 API：名字基本不变，仅 beforeDestroy → beforeUnmount destroyed → unmounted

  • 组合式 API：全部写成函数，并新增调试钩子。

Vue2 选项式 Vue3 选项式 Vue3 组合式 (setup)
beforeCreate beforeCreate 不需要（setup 自身就是）
created created 同上
beforeMount beforeMount onBeforeMount
mounted mounted onMounted
beforeUpdate beforeUpdate onBeforeUpdate
updated updated onUpdated
beforeDestroy beforeUnmount onBeforeUnmount
destroyed unmounted onUnmounted
activated activated onActivated
deactivated deactivated onDeactivated
— — onRenderTracked / onRenderTriggered（调试用）

# Vue3 去掉 beforeCreate/created

在 setup() 执行时组件实例已创建但尚未完成响应式初始化，天然相当于 Vue2 的 beforeCreate + created；因此组合式 API 不再需要这两个钩子。

# 父子组件生命周期顺序

  • 创建阶段：父 beforeCreate → 父 created → 父 beforeMount → 子 beforeCreate → 子 created → 子 beforeMount → 子 mounted → 父 mounted
  • 更新阶段：父 beforeUpdate → 子 beforeUpdate → 子 updated → 父 updated
  • 销毁阶段：父 beforeUnmount → 子 beforeUnmount → 子 unmounted → 父 unmounted

# mounted 不能保证所有子组件都挂载完毕

Vue 采用异步、批量 DOM 更新。

如果子组件内部也有异步组件或 nextTick，则子组件真正挂载完成的时间可能晚于父组件的 mounted。

此时若需等待整个视图渲染完毕，用 this.$nextTick 或 await nextTick()。

# Vue3 调试钩子 onRenderTracked/onRenderTriggered

用于开发阶段排查响应式系统：

  • onRenderTracked 收集渲染时读取了哪些响应式数据。
  • onRenderTriggered 某个依赖变化导致组件重新渲染。 配合 console.log 可以快速定位过度渲染。

# SSR 场景

在服务端渲染时，只有 beforeCreate 和 created 会执行；

所有与 DOM 相关的（beforeMount、mounted、beforeUpdate、updated、beforeUnmount、unmounted）都不会触发。

# 其他知识点

补点 一句话答案
1. 错误捕获钩子 Vue2: errorCaptured；Vue3: errorCaptured + 组合式 onErrorCaptured
2. 服务端数据预取 SSR 时把 AJAX 逻辑放在 asyncData（Nuxt）或 serverPrefetch（Vue3 选项式）里，而不是 created
3. 异步组件生命周期 异步组件加载时先触发 beforeCreate/created，等真正渲染时才进入 beforeMount+mounted；因此父 mounted 时子可能还没挂载
4. 被 <Suspense> 包裹时的额外钩子 Vue3 新增 onRenderTriggered 以外，还有 onPending / onResolve / onFallback（配合 Suspense 使用）
