      # SSR实现与原理

      # 项目文件结构

      • server-dev.ts：开发环境 SSR 服务器

      • server-prod.ts：生产环境 SSR 服务器

      • entry-client.ts：客户端入口，负责激活 SSR 渲染的静态页面

      • entry-server.ts：服务端入口，负责生成 SSR 静态 HTML

      • index.html：HTML 模板，承载 SSR 渲染结果

        文件 执行时机 执行环境 触发方式
        server-dev.ts 开发阶段每次启动服务时 Node.js（服务端） 手动执行 node server-dev.ts 或 npm script
        server-prod.ts 生产阶段每次启动服务时 Node.js（服务端） 手动执行 node server-prod.ts 或 pm2/docker 启动
        entry-server.ts 每个 HTTP 请求到达服务器时 Node.js（服务端） 被 server-dev.ts 或 server-prod.ts 内部 import 并调用 render(url)
        index.html 每次 SSR 渲染时读取一次 Node.js（服务端） 被 server-dev.ts/server-prod.ts 读取并替换占位符后返回
        entry-client.ts 浏览器加载完 HTML 后 Browser（客户端） <script type="module" src="/src/entry-client.ts"></script> 自动执行

      # 文件功能与核心代码

      # 1. server-dev.ts（开发服务器）

      功能

      • 使用 Vite 中间件模式，支持热更新
      • 读取 index.html 模板
      • 加载 entry-server.ts 渲染函数
      • 将渲染结果注入模板并返回

      核心代码

      const vite = await createViteServer({
  server: { middlewareMode: true },
  appType: "custom",
});

app.use(vite.middlewares);

app.use("*", async (req, res, next) => {
  const url = req.originalUrl;
  const template = await vite.transformIndexHtml(
    url,
    fs.readFileSync(path.resolve(__dirname, "index.html"), "utf-8")
  );
  const { render } = await vite.ssrLoadModule("/src/entry-server.ts");
  const { renderedHtml, state, ssrData } = await render(url);
  const html = template
    .replace(`<!--ssr-outlet-->`, renderedHtml)
    .replace(`<!--pinia-state-->`, state)
    .replace(`<!--ssr-data-->`, ssrData || {});
  res.status(200).set({ "Content-Type": "text/html" }).end(html);
});

      # 2. server-prod.ts（生产服务器）

      功能

      • 使用打包后的静态资源
      • 读取 dist/client/index.html 模板
      • 加载 dist/server/entry-server.js 渲染函数
      • 注入渲染结果并返回

      核心代码

      import { render } from "./dist/server/entry-server.js";

const template = fs.readFileSync(
  path.resolve(__dirname, "./dist/client/index.html"),
  "utf-8"
);

app.use("/assets", express.static("./dist/client/assets", { maxAge: "1000h" }));

app.use("*", async (req, res) => {
  const { renderedHtml, state } = await render(req.originalUrl);
  const html = template
    .replace(`<!--ssr-outlet-->`, renderedHtml)
    .replace(`<!--pinia-state-->`, state);
  res.status(200).set({ "Content-Type": "text/html" }).end(html);
});

      # 3. entry-client.ts（客户端激活）

      功能

      • 创建 Vue 应用实例
      • 恢复服务端注入的 Pinia 状态
      • 挂载应用到 DOM，完成激活（hydration）

      核心代码

      const { app, router, pinia } = createApp(false);

if (window.__INITIAL_STATE__) {
  pinia.state.value = JSON.parse(window.__INITIAL_STATE__);
  window.__SSR_DATA__ = JSON.parse(window.__SSR_DATA__);
}

router.isReady().then(() => {
  app.mount("#app");
});

      # 4. entry-server.ts（服务端渲染）

      功能

      • 创建 Vue 应用实例
      • 预取数据（如 clubInfo、clientInfo）
      • 渲染 HTML 字符串并返回状态与数据

      核心代码

      export const render = async (url: string) => {
  const { app, router, pinia } = createApp(true);
  await router.push(url);
  await router.isReady();

    // 存储pinia数据
  const [clubInfo, clientInfo] = await getAllSSrFetch("exampleClubId");
  useProductStore(pinia).initProductList(clubInfo);
  useClientInfoStore(pinia).initClientInfo(clientInfo);

  const renderedHtml = await renderToString(app);
  const state = JSON.stringify(pinia.state.value);
  const ssrData = JSON.stringify({ clubInfo, clientInfo });

  return { renderedHtml, state, ssrData };
};

      # 5. index.html（模板）

      功能

      • 提供 HTML 骨架
      • 预留占位符用于注入 SSR 渲染结果与状态

      核心代码

      <div id="app"><!--ssr-outlet--></div>
<script>
  window.__INITIAL_STATE__ = `<!--pinia-state-->`;
  window.__SSR_DATA__ = `<!--ssr-data-->`;
</script>
<script type="module" src="/src/entry-client.ts"></script>

      # SSR 原理总结

      1. 服务端渲染流程

        • 服务器根据请求路径，使用 entry-server.ts 渲染出 HTML 字符串
        • 将 HTML、Pinia 状态、SSR 数据注入模板
        • 返回完整 HTML 给浏览器

      2. 客户端激活流程

        • 浏览器加载静态资源
        • entry-client.ts 恢复 Pinia 状态与 SSR 数据
        • Vue 应用挂载到 DOM，完成激活（hydration）

      3. 开发 vs 生产

        • 开发环境使用 Vite 中间件，实时转换模块
        • 生产环境使用预打包的静态资源与渲染函数
